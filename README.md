# 🌷 Mayhan Garden — مهیان گاردن

**A modern, immersive 3D Persian (Farsi) e-commerce experience for an online flower shop.**

## ✨ Overview

**Mayhan Garden** is a fully responsive, RTL-first online flower boutique built with a modern React stack. It delivers a premium, animation-rich shopping experience with 3D card tilts, parallax hero, floating petals, a persistent cart, and a soft pastel floral identity — all in **Persian (Farsi)**.

## 🌸 Features

- 🌍 **Full Persian (Farsi) localization** with **RTL** layout across every section
- 🎨 **Floral pastel design system** built on OKLCH color tokens (no dark mode — a unique floral identity)
- 🪄 **3D micro-interactions** — mouse-tracked card tilts, perspective transforms, rotating product preview
- 🎬 **Smooth animations** powered by Framer Motion (parallax hero, scroll reveals, layout transitions)
- 🛒 **Persistent shopping cart** using Zustand + localStorage middleware
- 🌺 **Filterable shop** by flower category (Rose, Tulip, Sunflower, Orchid, Lavender, Peony)
- 💬 **Floating WhatsApp button** with pulse animation
- 🍃 **Ambient falling petals** for an immersive atmosphere
- 📱 **Fully responsive** mobile → desktop
- ⚡ **Lazy-loaded images** & optimized assets
- 🔎 **SEO-ready** with Persian meta tags, OG tags, and semantic HTML

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Framework | **TanStack Start** (React 19 + Vite 7, SSR-capable) |
| Styling | **Tailwind CSS v4** (via `@import` in `src/styles.css`) |
| Animations | **Framer Motion** |
| State | **Zustand** (with `persist` middleware) |
| UI Primitives | **shadcn/ui** + Radix UI |
| Typography | **Zain** (Persian-optimized font) |
| Language | **TypeScript** (strict) |
| Package Manager | **Bun** |
